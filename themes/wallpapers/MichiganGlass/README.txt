Michigan Glass — Sequoia Eleven

Native KDE light/dark pair. Select the package and switch based on Plasma style.
Eight PNG sizes per appearance, 1280x720 through 3440x1440.
Created with built-in image_gen from the supplied shoreline reference.
Generated sources were 1938x812; larger sizes are Lanczos-upscaled exports.
PROMPTS.json records the artwork prompts. These are raster assets and are
not regenerated by the legacy wallpaper.py vector-art builder.
Install through the Wallpaper component of the main Sequoia Eleven installer.
