# Rounded action icon trial

Selected Google Material Symbols Rounded SVGs, pinned to the revision and SHA-256
digests in `sources.json`. These are unfilled, weight 400, at optical sizes 20 and
24. See `LICENSE` (Apache-2.0); the existing MacTahoe artwork keeps its own license.

`python3 tools/tahoe_material.py` applies this layer to the checked-in Tahoe family
without a network connection. `tools/build-tahoe-icons.py` also applies it after
the upstream Tahoe transformation, so rebuilding does not erase the trial.

The explicit mapping in `tools/tahoe_material.py` covers common toolbar actions,
navigation, playback, notifications, volume/mute, Bluetooth, brightness, clipboard
and selected network indicators. It preserves other icons, including battery
levels and charging/error artwork. Full-color app and large folder art is untouched.
Existing duplicate names across actions/status/devices are updated so Qt lookup
cannot select a stale duplicate. Standard and symbolic names use KDE theme colors.
Wide glyphs receive a small optical inset to stay clear of the edge at 16 pixels.

Validation: `python3 tools/verify-tahoe-icons.py` checks rendering, theme lookup,
aliases, checksums, licenses and palette variants. The native SVG comparison sheet
is generated by `tools/preview-tahoe-material.py`; capture the old icons with its
`--capture-before` option before first applying the layer.
