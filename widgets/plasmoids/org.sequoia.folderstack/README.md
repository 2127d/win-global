# Sequoia Folder Stack

Based on Folder Stack 1.17 by XxKrustyxX, https://github.com/XxKrustyxX/plasma-stack.
Source imported from the installed Plasma package. GPL-2.0-or-later; see LICENSE.
The separate org.sequoia.folderstack ID protects this fork from upstream updates.

Keeps the original settings, previews, grid, subfolder stacks and file actions.
Sequoia adds staggered travel and icon growth from the dock, delayed labels,
reversible fold-back, and system animation-speed support. Fan mode opts out of
whole-window blur so the space between files stays transparent.

The setup uses this in place of org.sequoia.downloads. The migration installer
preserves each old widget's panel position and folder, and leaves other Folder
Stack instances (including Recent Files) unchanged.
